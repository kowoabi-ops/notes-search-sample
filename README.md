# Notes Search Sample Project

Sample implementation of a Notes app search feature inspired by Apple Notes.

## Features Implemented
- Keyword search across title, body, tags, attachments
- Search operators: `tag:work`, `attachment:pdf`, `locked:`, `shared:`, `checklist:`
- Basic natural language: "notes created last week", "modified today"
- Ranking: Top Hits prioritized by title match and recency
- Locked notes: only title searchable
- Suggested filters (drawings, attachments)
- Simulated OCR/image search via attachment metadata

## Evidence of Apple Notes Search
Based on official Apple Support:
- Searches body, handwritten (OCR), images (object recognition), scanned docs, PDFs, drawings
- Natural language queries
- Top Hits ranking
- Operators and tags
